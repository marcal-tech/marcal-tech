# jotabuilding

Construo produtos de IA para nichos que ninguém olha.

Tenho empresa e produzo conteúdo há anos. Há pouco tempo comecei a construir o
software que eu mesmo queria usar — e descobri que o gargalo nunca foi a
tecnologia, foi escolher um problema chato o suficiente para ninguém ter
resolvido direito.

## Construindo agora

**Razão** — assistente de IA para escritórios de contabilidade.

Auxiliar de escritório trava numa dúvida e interrompe o gerente cinco vezes por
dia. O Razão responde na hora, com os limites que a profissão exige: nunca
inventa fundamento legal, sempre sinaliza o que muda por município, sempre manda
validar com o responsável técnico.

`Next.js` · `TypeScript` · `Claude` · primeira versão rodando, procurando
escritórios para testar

## Como eu trabalho

- Produto no ar antes de plano de negócio. Validação vem de usuário, não de planilha.
- Nicho estreito e profundo, não mercado grande e raso.
- Design não é acabamento. É o que faz alguém confiar num produto novo.
